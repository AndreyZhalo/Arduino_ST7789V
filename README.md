# Подключение дисплея 2.4" TFT LCD (320x240, ST7789V) к Arduino Nano

[![Arduino](https://img.shields.io/badge/Arduino-Nano-00979D?logo=arduino)](https://www.arduino.cc/)
[![LCD](https://img.shields.io/badge/LCD-2.4%22%20TFT%20(ST7789V)-blue)](https://en.wikipedia.org/wiki/TFT_LCD)

Этот репозиторий содержит код и инструкции для подключения дисплея **2.4-дюймового TFT LCD с разрешением 320x240 пикселей на контроллере ST7789V** к плате **Arduino Nano**. Основная функция скетча - показ изображений в формате BMP с SD-карты

## ✨ Основные функции

* Инициализация дисплея ST7789V в режиме 240x320
* Чтение файлов изображений с SD-карты
* Поддержка формата **24-битных BMP-файлов**

## 📋 Необходимые компоненты

* Плата Arduino Nano (или совместимая)
* Дисплей 2.4" TFT LCD на контроллере ST7789V
* Модуль картридера SD-карты
* SD-карта (отформатированная в FAT16/FAT32)

## 🔌 Схема подключения

Подключение выполнено через интерфейс SPI.

| Компонент | Пин Arduino Nano |
|-----------|------------------|
| **TFT LCD (ST7789V)** | |
| `TFT_CS` (Chip Select) | 10 |
| `TFT_DC` (Data/Command) | 8 |
| `TFT_RST` (Reset) | 9 |
| `TFT_MOSI` (DATA) | 11 (Hardware SPI) |
| `TFT_SCK` (Clock) | 13 (Hardware SPI) |
| `VCC` | 5V |
| `GND` | GND |
| **SD Card Module** | |
| `SD_CS` (Chip Select) | 4 |
| `SD_MOSI` (DI) | 11 (Hardware SPI) |
| `SD_MISO` (DO) | 12 (Hardware SPI) |
| `SD_SCK` (Clock) | 13 (Hardware SPI) |
| `VCC` | 5V |
| `GND` | GND |

> **Важно:** Оба устройства (дисплей и SD-модуль) используют один и тот же hardware SPI (пины 11, 12, 13 на Nano). Они различаются пинами выбора (Chip Select, `TFT_CS` и `SD_CS`).

## 📚 Используемые библиотеки

Для работы скетча необходимо установить следующие библиотеки (через менеджер библиотек Arduino IDE):

* **Adafruit ST7789 ST7735 Library** by Adafruit (для работы с дисплеем)
* **Adafruit GFX Library** by Adafruit (графическая библиотека, зависимость для ST7789)
* **SD** (входит в стандартный набор Arduino)

## 🖼️ Подготовка изображений

Для корректного отображения изображения должны соответствовать следующим требованиям:

1. **Формат:** 24-битный BMP (`BMP 24 BPP`)
2. **Размер:** ровно **240x320** пикселей (соответствует ориентации дисплея в коде)
3. **Имена файлов:** сохраните их на SD-карту с именами, указанными в скетче (по умолчанию: `image1.bmp``)

> **Совет:** Для конвертации изображений можно использовать графические редакторы, такие как GIMP, Photoshop или онлайн-конвертеры. Убедитесь, что вы выбираете именно 24-битную глубину цвета при сохранении.

## 🚀 Использование

 ![Схема подключения](https://github.com/AndreyZhalo/Arduino_ST7789V/blob/main/schematic.png)
1. Соберите схему как показано выше
2. Отформатируйте SD-карту в файловую систему FAT16/FAT32
3. Подготовьте и скопируйте BMP-файлы на SD-карту
4. Установите необходимые библиотеки в Arduino IDE
5. Откройте скетч (`image.ino` файл) из этого репозитория
6. Загрузите скетч в Arduino Nano
7. Вставьте SD-карту в модуль картридера

После включения питания дисплей начнет показывать изображения с SD-карты.

## ⚙️ Настройка кода

Основные параметры для изменения в скетче:

* `tft.setRotation(2);` - поворот дисплея (значение от 0 до 3)
* `drawImage("image1.bmp");` - имена файлов для отображения

## ⚠️ Возможные проблемы и решения

* **"SD card initialization failed!" / "Image not found"**: Убедитесь, что SD-карта отформатирована, правильно подключена, а имена файлов в коде совпадают с именами на карте (учитывайте регистр букв)
* **Искаженное изображение**: Проверьте разрешение и формат BMP-файлов (должны быть 240x320, 24-bit). Также попробуйте изменить параметр `setRotation`
* **Дисплей не включается или мерцает**: Проверьте надежность подключения питания (5V и GND)
